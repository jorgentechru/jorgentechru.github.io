# JORGEN TECH — главное портфолио

Персональный сайт Егора — веб-разработчика, который создаёт сайты для магазинов и малого бизнеса. Сохранил тёмный стиль, фон с частицами, личное фото и интерактивную презентацию игры «Экобегун» из предыдущей версии портфолио. Главный акцент теперь — веб-разработка и живые проекты.

## Структура портфолио

- **Главный сайт:** этот репозиторий, `jorgentechru.github.io`.
- **JORGEN TECH PLANET:** https://jorgentechru.github.io/jorgen-tech-planet/ — самостоятельный интерактивный проект.
- **JORGEN TECH — Сантехника:** https://jorgentechru.github.io/jorgen-tech-plumbing/ — самостоятельная демоверсия (ссылка заработает после публикации соответствующего репозитория).
- **Экобегун:** описание, видео и презентация внутри главного портфолио.

Другие проекты не нужно переносить внутрь этого репозитория: каждый продолжит жить и обновляться отдельно.

## Как сделать главным сайтом на GitHub Pages

1. Создайте **публичный** репозиторий с названием **`jorgentechru.github.io`**: https://github.com/new. Важно, чтобы название точно совпадало с логином GitHub + `.github.io`.
2. Распакуйте ZIP и откройте папку `jorgentechru.github.io`.
3. Выделите **все файлы и папки внутри неё**, включая `index.html`, `style.css`, `script.js` и `assets`. Перетащите их в GitHub через **Upload files**. Не загружайте целый ZIP и не создавайте вложенную папку второго уровня.
4. Нажмите **Commit changes**.
5. В репозитории откройте **Settings → Pages → Build and deployment** и выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/ (root)`
6. Нажмите **Save** и дождитесь публикации. Адрес главного сайта будет:

   **https://jorgentechru.github.io/**

Никакой сборки, установки пакетов или файла `deploy.yml` не требуется: это статические HTML/CSS/JS-файлы с относительными путями.

## Примечания

- Сайт адаптивный, а фоновая анимация ограничивает количество частиц, выключается во вкладке в фоне и учитывает `prefers-reduced-motion`.
- Видео и PDF «Экобегуна» остались локальными файлами, что позволяет показывать проект без стороннего видеохостинга.
- Демоверсия магазина сантехники сама по себе не принимает реальные заказы.
- После первой публикации проверьте ссылки на живые проекты; если демо-магазин ещё не опубликован, он честно помечен на сайте как ожидающий публикации.
